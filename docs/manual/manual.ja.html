Web-Socket Audio Controller Stream Deck プラグイン 取扱説明書

2026-11-14 · バージョン 1.0.3

Stream Deck から OBS 音声ミキサーの音量、ミュート、モニタリング、バランスを操作し、キーとダイヤルの画面でレベルメーターを表示するプラグインです。

作者: 김탄2(Kimtan2)

必要なもの

項目必要なもの
パソコンWindows 10 以降
Stream Deck アプリStream Deck ソフトウェア 7.3 以降
OBSOBS Studio 30 以降 (obs-websocket 5 を内蔵)
インストールファイル.streamDeckPlugin ファイル (例: Web-Socket-Audio-Controller.streamDeckPlugin)

Stream Deck + があればダイヤルアクション(VU Dial、Balance Dial)も使えます。ほかの Stream Deck ではキーアクションのみ使えます。

手順1: プラグインをインストール

  1. .streamDeckPlugin ファイルをダブルクリックします。

  2. Stream Deck アプリが開き、インストールするか確認されます。インストールを押します。

  3. すでにインストール済みの場合は上書きするか確認されることがあります。その場合もインストールを選びます。

  4. Stream Deck アプリ右側のアクション一覧に Web-Socket Audio Controller カテゴリーが追加されたことを確認します。

手順2: OBS で WebSocket をオンにする

プラグインは OBS に内蔵された WebSocket サーバーを通して OBS とやり取りします。OBS で一度だけ設定します。

  1. OBS のメニュー ツール → WebSocket サーバー設定を開きます。

  2. WebSocket サーバーを有効にするをオンにします。

  3. サーバーポートを確認します。初期値は 4455 です。

  4. 認証を有効にするがオンなら、接続情報を表示を押してサーバーパスワードを控えておきます。手順3で使います。

  5. OK を押して閉じます。

手順3: プラグインを接続

OBS で認証をオフにしている場合、プラグイン側は初期値のままで動きます。オンにしている場合はパスワードだけ入力します。

  1. Web-Socket Audio Controller のアクションをどれか一つキーにドラッグし、クリックします。

  2. 下の設定画面のいちばん下にある ▶ OBS connection (WebSocket) を押して開きます。(普段は閉じています)

  3. 値を確認または変更します。ここでの変更はすべてのアクションに適用されます。

項目初期値意味
Host127.0.0.1OBS が動いているパソコンのアドレス (同じパソコンならそのまま)
Port4455OBS のサーバーポートと同じにする
Password空欄OBS で認証をオンにしている場合、そのパスワード

値を変えるとすぐに再接続します。Stream Deck を再起動する必要はありません。OBS が起動していないとキーに OFFLINE と表示され、3秒ごとに再接続を試みます。

言語の変更: 同じ設定画面のいちばん下の ▶ Language を開き、English / 한국어 / 日本語 から選びます。選ぶとすぐに設定画面の文字とキーの文字(MUTED、OFFLINE など)が切り替わり、すべてのアクションに適用されます。初期値は English です。アクション一覧のアクション名は変わりません。

接続できたかの確認: キーに OFFLINE が表示されず、設定画面の Source 一覧に OBS の音声ソース名(例: マイク、デスクトップ音声)が出ていれば接続できています。

手順4: 最初のキーを作る

キー一つでマイクをミュートする例です。すべての Stream Deck で使えます。

  1. アクション一覧の Web-Socket Audio Controller → Mute を空いているキーにドラッグします。

  2. キーをクリックし、下の設定画面の Source でマイクのソースを選びます。音声のないソース(画像、ブラウザなど)は一覧に出ません。

  3. 押すたびにミュートがオン・オフします。ミュート中は赤い背景の中央にソース名と MUTED(日本語設定ではミュート)が表示されます。

OBS でソース名を変えても、キーの設定はそのまま使えます。

キー2つで音量フェーダーを作る

キー2つでマイクの音量を上げ下げする例です。すべての Stream Deck で使えます。

  1. Fader(2-Button) を上下に並んだ2つのキーに一つずつドラッグします。

  2. 上のキーをクリックし、Source でマイクを、Role で Top (up) を選びます。

  3. 下のキーも同じソースを選び、Role だけ Bottom (down) にします。

  4. 上のキーで音量が 1 dB 上がり、下のキーで 1 dB 下がります。押し続けると動き続けます。一度に動く量は Step (dB) で変えられます(例: 0.5、2)。

左右に並べる場合は、Role を Left (down) と Right (up) にします。

画面の見方 (上下に並べた場合):

  • 上のキーの上部: ソース名と現在の音量

  • 下のキーの下部: 現在の音声レベル

  • 2本のバー(L/R): 入ってくる音の大きさ。2つのキーにまたがってつながり、目盛りは OBS と同じ −60 〜 0 dB

  • バーの中の青い線: 音量(フェーダー)の位置

  • MUTED: ミュート中 (バーは灰色で動き続けます)

フェーダーの大きさをそろえるため、ソース名は常に1行で表示します。長い名前は末尾が … になるので、Display name に短い名前を入れてください。このアクションではミュートできません。ミュートもキーで行うなら Mute アクションを追加してください。

Stream Deck + の場合: VU Dial を作る

Stream Deck + のダイヤルでマイクの音量を調整する例です。

  1. VU Dial をダイヤル枠にドラッグします。

  2. 設定画面の Source でマイクを選びます。

  3. ダイヤルを1目盛り回すごとに音量が 1 dB 変わります。1目盛りの量は Step per tick (dB) で変えられます(例: 0.5、2)。押して離すとミュートがオン・オフします。

画面の見方:

  • 上: ソース名

  • 2本のバー(L/R): 入ってくる音の大きさ (緑 → 黄 → 赤)

  • バーの中の青い線: 音量の位置

  • 左下 / 右下: 音声レベル / 音量

  • MUTED: ミュート中

画面をタッチしてもミュートします。誤ってタッチしてしまう場合は Touch tap mutes をオフにしてください。左下のレベルは Level text で L/R 別々(L -14.0 R -18.0)か一つの値(Combined、-14.0 dB)を選べます。

押したときの動作を変える: 設定画面の ▶ Press actions を押して開きます。(普段は閉じています)

  • Press: 押して離したとき。Mute toggle(初期値)または Recall volume

  • Press + turn left / right: 押したまま左 / 右に回したとき。Step volume(初期値)、Mute toggle、Mute on、Mute off、Recall volume

  • Recall volume を選ぶと、その下に Recall volume (dB) 欄が出ます。戻したい音量を入力します(例: −20)。

押したまま回した場合、離したときの押下動作は実行されません。

アクション一覧

キーはすべての Stream Deck で、ダイヤルは Stream Deck + でのみ使えます。

アクション種類できること
VU Dialダイヤル回して音量調整(初期値 1目盛り 1 dB)、押すかタッチでミュート、レベルメーター表示
Balance Dialダイヤル回すと左右バランスを表示値で 1 ずつ(例: L 40 → L 39)、押すと中央
Fader(2-Button)キー2つキー2つで音量を上げ下げ(初期値 1回 1 dB)、2つのキーにまたがるメーター表示
Muteキーミュートのオン・オフ。ミュート中は赤い背景
Volumeキー音量を指定値にする(Set to)か、指定量だけ上げ下げ(Step by)。メーター表示
Push to talk / Push to muteキー押している間だけ音が出る(talk)か、止まる(mute)
Talkbackキーほかのソースをまとめてミュートまたは下げ、離す(またはもう一度押す)と元に戻す
Audio monitoringキー音声モニタリングをオフ / モニターのみ / モニターと出力 に切り替え
Balanceキー左右バランスを指定値にするか、指定量だけ動かす

押し続けると繰り返すキー(Fader(2-Button)、Step by の Volume と Balance)は、繰り返しが止まらないときにそのキーをもう一度押すと止まります。

Volume と Balance キー

Volume: Mode で選びます。

  • Set to: Volume (dB) に入力した値にします(例: −20)。

  • Step by: 入力した量だけ上げ下げします(例: 1 または −1)。押し続けると動き続けます。

音量の範囲は OBS のスライダーと同じ −∞ 〜 0 dB です。−60 dB より下げると −∞(無音)になり、−∞ から上げると −60 dB になります。

Balance: Mode を選び、Balance に値を入力します。

  • Set to: −100 = L 100、0 = 中央、100 = R 100 (例: −40 → L 40)

  • Step by: 5 = 右へ 5、−5 = 左へ 5

Push to talk / Push to mute

  1. Push to talk / Push to mute をキーに置き、Source でマイクを選びます。

  2. Mode で選びます。Push to talk は押している間だけ音が出て、Push to mute は押している間だけ音が止まります。

  3. Release delay (ms): 離してから元に戻すまでの待ち時間です(初期値 200 ms、OBS の PTT と同じ)。言葉の終わりが切れないようにします。

キーにはソース名と動作(Push to talk または Push to mute、日本語設定では押して話す / 押してミュート)が表示されます。音が出ている間は緑の背景、止まっている間は文字が赤になります。

  • 押した瞬間のミュート状態を覚えておき、離すと押す前の状態に戻します。すでにミュートのマイクで Push to mute を押して離しても、マイクはオンになりません。

  • 押している間にページを切り替えるとすぐに戻します。OBS との接続が切れている間に離した場合は、再接続した瞬間に戻します。

  • マルチアクションの中では動作しません。キーを離した信号が確実ではなく、マイクがオンのまま残るおそれがあるためです。

Talkback (トークバック)

話している間、BGM やゲームの音をまとめて下げるキーです。

  1. Talkback をキーに置きます。

  2. Target で選びます。All except the list はリストのソース(普通は自分のマイク)以外すべて、Only the list はリストのソースだけを下げます。

  3. + Add Source を押して、ソースを1行ずつ追加します。行の右の × で削除します。

  4. Style で下げ方を選びます。

  5. Behavior で While held(押している間だけ)か Toggle(一度押すとオン、もう一度押すとオフ)を選びます。

Styleできること
Mute対象ソースをミュート
Set volumeVolume (dB) の音量まで下げる(初期値 −30)。すでにそれより小さいソースはそのまま
Talkback現在の音量から Lower by (dB) だけ下げる(初期値 15)

  • オンの間はキーがオレンジ色になります。すでにミュートのソースには触れません。

  • オフにすると、すべてのソースを押す前の値に戻します。

  • 複数の Talkback キーが同じソースを使っている場合、一つをオフにすると、そのソースを使っているほかのキーも一緒にオフになり、表示もオフに変わります。

  • Stream Deck アプリやパソコンを再起動しても元の値を覚えています。While held は OBS に接続するとすぐに戻し、Toggle はオンのまま続きます。

  • Toggle がオンのままキーを削除すると、ソースが下がったまま残ります。オフにしてから削除してください。

  • マルチアクションの中では Toggle だけが動作します。

Audio monitoring

OBS のオーディオの詳細プロパティにある音声モニタリングをキーで切り替えます。Mode で選びます。

Modeできること
Set toMonitoring で選んだ値(Monitor off / Monitor only / Monitor and output)にする
Toggle with off押すたびにオフと選んだ値を切り替える
Cycle押すたびにオフ → モニターのみ → モニターと出力 の順に切り替える

キーにはソース名と現在のモニタリングが表示され、モニタリングがオンの間は青い背景になります。

メーターの設定

メーターのあるアクション(VU Dial、Fader(2-Button)、Volume)には Meter style があります。OBS の設定 → 音声 → ピークメーターの種類と同じ方を選んでください。

Meter styleOBS の設定色の範囲
Standardサンプルピーク黄 −20 dB から、赤 −9 dB から
Wide greenトゥルーピーク黄 −13 dB から、赤 −2 dB から

OBS はプラグインにサンプルピークの値だけを送ります。そのため Wide green は色の範囲だけが OBS と同じで、大きな音が出たときに OBS の画面よりわずかに低く見えることがあります。メーターは OBS と同じようにピークがゆっくり下がり、ピークホールドの印が 20 秒残ります。

メーター範囲: 設定画面のいちばん下の ▶ Meter range(日本語設定ではメーター範囲)を開き、Start(開始点)でメーターが始まる値を -60 / -50 / -40 / -30 dB から選びます。初期値は -60 dB(OBS と同じ)で、選ぶとすぐにすべてのキーのメーターに適用されます。たとえば -40 を選ぶと -40 〜 0 dB だけが広く表示され、話し声の範囲が見やすくなります。変わるのは表示の範囲だけで音量の調整範囲はそのままです。開始点より小さい音はメーターの端に表示されます。

キーの表示を変える

ソース名を変える: 設定画面の Display name に好きな名前を入力します。空欄なら OBS のソース名が出ます。Stream Deck アプリのタイトル欄を使うとプラグインの文字と重なるので、名前は Display name で変えてください。

状態ごとに見た目を変える: Mute、Push to talk / Push to mute、Talkback、Audio monitoring のキーには状態が2つあります。

  1. Stream Deck アプリでそのキーをクリックします。

  2. アイコンの下にある2つの点を確認します。それぞれの点がどの状態かは下の表を見てください。

  3. 点を押してから、その状態で表示するアイコンとタイトルを設定します。

キー左の点右の点
Muteソースの音が出ているときソースの音が消えているとき(ミュート)
Talkbackほかのソースの音がそのまま出ているときほかのソースの音が消えた、または下がったとき(トークバック オン)
Push to talkソースの音が出ているとき(押している間)ソースの音が消えているとき(普段、押していないとき)
Push to muteソースの音が出ているとき(普段、押していないとき)ソースの音が消えているとき(押している間)
Audio monitoringモニタリングがオフのときモニタリングがオン(モニターのみ、またはモニターと出力)のとき

タイトルを入れると、プラグインが描く名前と状態の文字は消えます(背景色はそのまま)。自分で設定したアイコンが表示されている間は、OFFLINE などの表示が見えないことがあります。点が一つしか見えない場合は、古いバージョンで置いたキーです。そのキーを削除して、アクション一覧からもう一度ドラッグしてください。
