Web-Socket Audio Controller Stream Deck Plugin Manual

2026-11-14 · Version 1.0.3

A plugin that controls the volume, mute, monitoring and balance of the OBS audio mixer from a Stream Deck, and shows level meters on the keys and dial screens.

Made by 김탄2 (Kimtan2)

What you need

ItemRequirement
ComputerWindows 10 or later
Stream Deck appStream Deck software 7.3 or later
OBSOBS Studio 30 or later (includes obs-websocket 5)
InstallerA .streamDeckPlugin file (e.g. Web-Socket-Audio-Controller.streamDeckPlugin)

With a Stream Deck + you can also use the dial actions (VU Dial, Balance Dial). Other Stream Decks use the key actions only.

Step 1: Install the plugin

  1. Double-click the .streamDeckPlugin file.

  2. The Stream Deck app opens and asks whether to install it. Click Install.

  3. If it is already installed, it may ask to replace it. Choose install again.

  4. Check that the Web-Socket Audio Controller category appears in the action list on the right of the Stream Deck app.

Step 2: Turn on WebSocket in OBS

The plugin talks to OBS through its built-in WebSocket server. Set this up once in OBS.

  1. Open Tools → WebSocket Server Settings in OBS.

  2. Turn on Enable WebSocket server.

  3. Check the Server Port. The default is 4455.

  4. If Enable Authentication is on, click Show Connect Info and note the Server Password for step 3.

  5. Click OK to close the window.

Step 3: Connect the plugin

If authentication is off in OBS, the plugin's defaults work as they are. If it is on, you only need to enter the password.

  1. Drag any action from Web-Socket Audio Controller onto a key and click it.

  2. At the very bottom of the settings screen, click ▶ OBS connection (WebSocket) to unfold it. (It is folded by default.)

  3. Check or change the values. They apply to every action.

FieldDefaultMeaning
Host127.0.0.1Address of the PC running OBS (keep it for the same PC)
Port4455Must match the OBS Server Port
PasswordemptyThe OBS password, if authentication is on

Changes reconnect right away; no restart is needed. While OBS is not running the keys show OFFLINE, and the plugin retries every 3 seconds.

Changing the language: unfold ▶ Language at the bottom of the same screen and pick English / 한국어 / 日本語. The settings screen and the text on the keys (MUTED, OFFLINE and so on) change at once, for every action. The default is English; action names in the action list do not change.

How to tell it is connected: no key shows OFFLINE, and the Source list on the settings screen shows your OBS audio sources (e.g. Mic/Aux, Desktop Audio).

Step 4: Make your first key

This example mutes your microphone with one key. It works on every Stream Deck.

  1. Drag Web-Socket Audio Controller → Mute onto an empty key.

  2. Click the key and pick your microphone in Source. Sources without audio (images, browsers and so on) are not listed.

  3. Each press turns mute on or off. While muted the key turns red, with the source name and MUTED in the middle.

Renaming the source in OBS keeps the key working.

A volume fader on two keys

This example raises and lowers the microphone volume with two keys. It works on every Stream Deck.

  1. Drag Fader(2-Button) onto two keys, one directly above the other.

  2. Click the top key, pick the microphone in Source and Top (up) in Role.

  3. Give the bottom key the same source, and Bottom (down) in Role.

  4. The top key raises the volume by 1 dB, the bottom key lowers it by 1 dB. Hold a key to keep moving. Change the amount in Step (dB) (e.g. 0.5, 2).

For two keys side by side, pick Left (down) and Right (up) as the roles.

Reading the keys (stacked vertically):

  • Top of the upper key: source name and current volume

  • Bottom of the lower key: current audio level

  • Two bars (L/R): the incoming level, running across both keys, on the OBS scale of −60 to 0 dB

  • Blue line inside the bars: volume (fader) position

  • MUTED: the source is muted (the bars keep moving in grey)

The source name always takes one line so every fader has the same size. Long names end in …; enter a short name in Display name. This action cannot mute; add a Mute key for that.

With a Stream Deck +: VU Dial

This example controls the microphone volume with a Stream Deck + dial.

  1. Drag VU Dial onto a dial slot.

  2. Pick the microphone in Source.

  3. Each tick changes the volume by 1 dB. Change the amount in Step per tick (dB) (e.g. 0.5, 2). Pressing the dial toggles mute.

Reading the screen:

  • Top: source name

  • Two bars (L/R): the incoming level (green → yellow → red)

  • Blue line inside the bars: volume position

  • Bottom left / right: audio level / volume

  • MUTED: the source is muted

Tapping the screen also mutes. If that happens by accident, turn off Touch tap mutes. The level at the bottom left can show L and R separately (L -14.0 R -18.0) or one value (Combined, -14.0 dB); choose in Level text.

Changing the press actions: unfold ▶ Press actions on the settings screen. (It is folded by default.)

  • Press: press and release. Mute toggle (default) or Recall volume

  • Press + turn left / right: turning while pressed. Step volume (default), Mute toggle, Mute on, Mute off, Recall volume

  • With Recall volume, a Recall volume (dB) field appears below it. Enter the volume to go back to (e.g. −20).

If you turned the dial while pressing, the press action does not run on release.

Action list

Key actions work on every Stream Deck; dial actions need a Stream Deck +.

ActionTypeWhat it does
VU DialDialTurn for volume (1 dB per tick by default), press or tap to mute, shows a level meter
Balance DialDialTurn to move the balance by 1 as shown (e.g. L 40 → L 39), press to centre
Fader(2-Button)2 keysRaise/lower the volume with two keys (1 dB per press by default), meter across both keys
MuteKeyMute on/off. Red while muted
VolumeKeySet the volume to a value (Set to) or move it by an amount (Step by). Shows a meter
Push to talk / Push to muteKeySound goes out (talk) or is blocked (mute) only while held
TalkbackKeyMutes or lowers other sources at once; release (or press again) to put them back

BalanceKeySet the balance to a value or move it by an amount

Keys that repeat while held (Fader(2-Button), Volume and Balance in Step by) can be stopped by pressing the key once more if a repeat does not stop.

Volume and Balance keys

Volume: choose in Mode.

  • Set to: sets the volume to Volume (dB) (e.g. −20).

  • Step by: moves the volume by that amount (e.g. 1 or −1). Hold to keep moving.

The range matches the OBS slider: −∞ to 0 dB. Going below −60 dB gives −∞ (silent); going up from −∞ gives −60 dB.

Balance: choose in Mode and enter a value in Balance.

  • Set to: −100 = L 100, 0 = centre, 100 = R 100 (e.g. −40 → L 40)

  • Step by: 5 = 5 to the right, −5 = 5 to the left

Push to talk / Push to mute

  1. Put Push to talk / Push to mute on a key and pick the microphone in Source.

  2. Choose in Mode. Push to talk lets sound out only while held; Push to mute blocks it only while held.

  3. Release delay (ms): how long to wait after release before switching back (default 200 ms, like OBS's PTT). It keeps the end of a sentence from being cut.

The key shows the source name and its mode (Push to talk or Push to mute). It is green while sound goes out; the text is red while it is blocked.

  • The key remembers the mute state at the moment you press it and goes back to that state on release. Push to mute on an already-muted microphone does not unmute it on release.

  • Switching pages while holding puts it back at once. Releasing while OBS is disconnected puts it back the moment it reconnects.

  • It does not work inside a Multi Action: the release is not reliable there, and the microphone could stay on.

Talkback

A key that lowers music or game audio all at once while you talk.

  1. Put Talkback on a key.

  2. Choose in Target: All except the list lowers every source except those in the list (usually your microphone); Only the list lowers only the listed sources.

  3. Click + Add Source to add sources one row at a time. Remove a row with its ×.

  4. Choose how to lower them in Style.

  5. Choose While held or Toggle (press once to turn on, again to turn off) in Behavior.

StyleWhat it does
MuteMutes the target sources
Set volumeLowers them to Volume (dB) (default −30). Sources already quieter stay as they are
TalkbackLowers them by Lower by (dB) from their current volume (default 15)

  • The key turns orange while on. Sources that are already muted are left alone.

  • Turning it off puts every source back to its value from before the press.

  • If several Talkback keys hold the same source, turning one off also turns off the others holding that source, and their keys show off.

  • The original values survive a restart of the Stream Deck app or the PC. While held is put back as soon as OBS connects; Toggle stays on.

  • Deleting a key while its Toggle is on leaves the sources lowered, so turn it off first.

  • Inside a Multi Action only Toggle works.

Audio monitoring

Switches the Audio Monitoring setting from OBS's Advanced Audio Properties. Choose in Mode.

ModeWhat it does
Set toSets the value chosen in Monitoring (Monitor off / Monitor only / Monitor and output)
Toggle with offEach press switches between off and the chosen value
CycleEach press goes off → monitor only → monitor and output

The key shows the source name and the current monitoring; it turns blue while monitoring is on.

Meter settings

Actions with a meter (VU Dial, Fader(2-Button), Volume) have Meter style. Match OBS Settings → Audio → Peak Meter Type.

Meter styleOBS settingColour ranges
StandardSample Peakyellow from −20 dB, red from −9 dB
Wide greenTrue Peakyellow from −13 dB, red from −2 dB

OBS sends the plugin sample-peak values only, so Wide green matches OBS in its colour ranges only; loud peaks may read slightly lower than in OBS. Like OBS, the meter falls back gradually and shows a peak-hold mark for 20 seconds.

Meter range: unfold ▶ Meter range at the bottom of the settings screen and pick where the meters start in Start: -60 / -50 / -40 / -30 dB. The default is -60 dB, as in OBS, and the choice applies to every key at once. With -40, for example, only -40 to 0 dB is shown, wider, so speech levels are easier to read. Only what the meters show changes, not the volume range; sound below the start sits at the low end of the meter.

Changing what a key shows

Renaming the source: enter a name in Display name on the settings screen. Empty shows the OBS source name. The Stream Deck app's own title would overlap the plugin's text, so rename with Display name.

A different look for each state: the Mute, Push to talk / Push to mute, Talkback and Audio monitoring keys have two states.

  1. Click the key in the Stream Deck app.

  2. Find the two dots under the icon. The table below shows which state each dot is.

  3. Click a dot, then set the icon and title for that state.

KeyLeft dotRight dot
Mutethe source's sound is going outthe source's sound is off (muted)
Talkbackthe other sources sound as usualthe other sources are off or lowered (Talkback on)
Push to talkthe source's sound is going out (while pressed)the source's sound is off (usually while not pressed)
Push to mutethe source's sound is going out (usually while not pressed)the source's sound is off (while pressed)
Audio monitoringmonitoring is offmonitoring is on (monitor only, or monitor and output)

With a title set, the plugin hides its own name and status text (the background colour stays). While your own icon is shown, signs such as OFFLINE may not be visible. If you see only one dot, the key was placed with an older version; delete it and drag it in again from the action list.
