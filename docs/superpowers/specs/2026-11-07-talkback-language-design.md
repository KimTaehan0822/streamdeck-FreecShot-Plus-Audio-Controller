# 토크백(Talkback) 액션 + 언어 선택 설계

날짜: 2026-11-07 · 대상 저장소: `streamdeck-obs-audio` (OBS Audio 스트림덱 플러그인)

## 왜 만드나

방송 중 키 하나로 "다른 소스들 소리를 한꺼번에 줄이거나 끄고, 끝나면 원래대로" 돌리고 싶다. PTT를 쓰다가 나온 아이디어다.
그리고 이 플러그인을 다른 사용자도 쓰도록, 설정 화면과 키 글자를 한국어/영어/일본어 중에서 고를 수 있어야 한다.

## 목표

1. 새 키 액션 **Talkback**(한국어 표시 "토크백").
   - 대상: 소스 목록 + "목록 제외 / 목록만" 선택.
     - **목록 제외**: 목록에 있는 소스를 뺀 모든 오디오 소스(OBS 믹서에 보이는 소스, 기존 소스 목록과 같은 기준).
     - **목록만**: 목록에 있는 소스에만 적용.
     - 목록은 처음에 한 줄, **Add Source** 버튼으로 한 줄씩 추가, 줄마다 삭제 버튼. 메뉴가 복잡하지 않게.
   - 줄이는 방식(하나 선택):
     - **음소거**: 대상 소스를 음소거.
     - **정한 볼륨**: 대상 소스 볼륨을 정한 dB로 내림(예: −30 dB, −∞ 가능). 이미 그보다 작은 소스는 그대로.
     - **토크백**: 지금 볼륨에서 정한 dB만큼 줄임(예: 15 → 지금 −6 dB면 −21 dB). −∞인 소스는 −∞ 그대로.
   - 동작(하나 선택):
     - **누르는 동안**: 누르면 적용, 떼면 누르기 전 값으로 되돌림(PTT와 같은 방식).
     - **토글**: 한 번 누르면 적용, 다시 누르면 되돌림.
   - **이미 음소거된 소스는 건드리지 않는다**(적용도 복구도 하지 않음).
   - 되돌릴 때는 **누르기 전 값**으로 되돌린다. 적용 중에 사용자가 그 소스를 직접 바꿨더라도 누르기 전 값이 이긴다(PTT와 같음).
2. **Language** 설정: 설정 화면 맨 아래(연결 설정 아래)에 한국어 / English / 日本語 선택.
   - 바뀌는 범위: 설정 화면의 모든 문구 + 키에 뜨는 글자(MUTED, TALK, OFFLINE, SET SOURCE, SETUP, MON, MON+OUT, OFF, 토크백 키 글자 등).
   - 플러그인 전체 공통(한 키에서 바꾸면 모든 키에 적용). 기본값: English.

## 하지 않는 것

- 다이얼용 토크백(키만).
- 스트림덱 앱의 액션 목록 이름(manifest)은 앱 언어를 따르므로 이 설정으로 바꾸지 않는다. 액션 이름은 영어 "Talkback".
- 적용 중에 새로 생긴 소스는 영향받지 않는다(누른 순간의 대상만).
- PTT 키와 토크백 키 사이의 조율(아래 "알려진 한계").

## 실패로 보는 것

- 떼거나 껐는데 어떤 소스가 줄어든 채/음소거된 채 남는 것(방송 사고). 연결이 끊겼다 돌아와도, 키가 사라져도, 플러그인/앱이 재시작돼도 결국 원래대로 돌아와야 한다.
- 원래 음소거였던 소스가 토크백 후 음소거가 풀리는 것.
- 설정 화면이 복잡해지는 것.

## 접근 방식 (선택: A)

| | 방법 | 결과 |
|---|---|---|
| **A (선택)** | 누르는 순간 대상 소스들의 원래 볼륨·음소거를 기억, 되돌릴 때 그 값으로 | 세 방식 모두 지원, PTT 안전장치 재사용, 원래 값을 키 설정에 저장해 재시작에도 복구. OBS 설정을 건드리지 않음 |
| B | OBS 소스마다 게인 필터를 만들어 켜고 끄기 | OBS 장면에 필터가 쌓이고, 게인 필터는 −30 dB까지라 음소거/정한 볼륨 불가 |
| C | 기억 없이 −X dB / +X dB만 보내기 | 적용 중 조절이나 −∞에서 원래 값이 틀어짐, 음소거/정한 볼륨 불가 |

언어: **A(선택)** 플러그인 전역 설정 `language` + 번역표(설정 화면용, 키 글자용). B(스트림덱 앱 언어 따라가기)는 선택이 안 돼서 제외.

## 동작 상세 (사용자가 정한 것)

- 적용 시점의 대상 = 그 순간 OBS에 있는 오디오 소스 중 (모드에 따라) 목록 제외/목록만, 그리고 **음소거되지 않은 것**.
- 기억하는 값: 소스마다 원래 볼륨(배율, 정확히 되돌리기 위해)과 "이 키가 음소거시켰는지".
- 복구:
  - 음소거 방식: 이 키가 음소거한 소스만 음소거 해제.
  - 정한 볼륨/토크백 방식: 기억한 원래 볼륨으로 설정.
  - 복구 때 OBS에 없는 소스(삭제됨)는 건너뜀.
- 누르는 동안 방식: 떼는 즉시 복구(PTT의 "Release delay"는 넣지 않음 — 제 판단, 필요하면 추가 가능).
- 토글 방식: 켜진 동안 키를 강조 표시. 다시 누르면 복구.
- 안전장치(PTT와 같은 원칙):
  - 복구할 때 OBS 연결이 끊겨 있으면, 다시 연결되는 즉시 복구.
  - 키가 화면에서 사라지면(페이지 이동, 키 삭제): 누르는 동안 방식은 즉시 복구. **토글 방식은 켜진 상태 유지**(다른 페이지로 넘겨도 계속 줄어든 상태가 의도일 수 있음 — 제 판단).
  - 원래 값은 **저장해 둔다**(저장 위치는 아래 "검토 후 정한 것"). 플러그인/스트림덱 앱/PC가 다시 켜지면:
    - 토글 방식: 켜진 상태로 이어서 표시, 다시 누르면 저장된 값으로 복구(사용자 선택).
    - 누르는 동안 방식: 손이 떨어진 상태이므로 OBS에 연결되는 즉시 복구.

### 검토 후 정한 것

사용자가 정함:
- **정한 볼륨 방식은 줄이기만 한다**: 정한 값보다 큰 소스만 그 값으로 내리고, 이미 작은 소스는 건드리지 않는다(기억도 안 함).
- **토글이 켜진 키가 화면에서 사라져도(페이지 이동이든 삭제든) 켜진 채 유지.** 켜진 키를 삭제하면 소스가 줄어든 채 남는 것은 사용자가 받아들임 → 위 "실패로 보는 것"의 예외.

제 판단(마음에 안 들면 바꿀 수 있음):
- **원래 값 저장 위치**: 키 설정이 아니라 플러그인 폴더의 상태 파일(예: `talkback-state.json`)에 키(액션 id)별로 저장. 이유: 설정 화면이 키 설정 전체를 덮어쓸 수 있고, 키 설정은 그 키가 화면에 나타나야만 읽을 수 있어서. 플러그인이 시작하면 파일을 읽어서:
  - 누르는 동안 방식으로 저장된 것 → OBS 연결 후 바로 복구.
  - 토글 방식으로 저장된 것 → 그 키는 켜진 상태로 표시, 다시 누르면 복구.
- 저장 내용: 적용한 방식·동작, 소스별(UUID) 원래 볼륨 배율과 "이 키가 음소거했는지". 적용 중에 키 설정(방식·목록·dB)을 바꿔도 복구는 저장된 내용대로.
- **OBS 재시작/재연결 후 복구**: 소스 목록을 다 받은 뒤에 복구(기존 연결 코드는 목록을 다 받은 다음에야 "연결됨"으로 바뀌므로 재연결 신호 시점에 복구하면 됨). 그때도 없는 소스는 삭제된 것으로 보고 건너뜀.
- **멀티 액션 안**: 누르는 동안 방식은 무시(PTT와 같음, 손 뗌 신호가 믿을 수 없어서), 토글은 동작.
- 대상 소스는 OBS UUID로 저장(이름은 표시용). OBS에서 이름을 바꿔도 목록이 유지됨.
- `language`는 OBS 연결 설정과 같은 전역 설정에 두되, 언어만 바뀌면 OBS 재연결은 하지 않음.

## 키 화면

- 위: 표시 이름(설정의 Display name, 비면 "Talkback"/"토크백"/"トークバック").
- 가운데: 방식 요약 — 음소거면 "MUTE"(번역), 정한 볼륨이면 "−30 dB", 토크백이면 "−15 dB" 앞에 "▼" 같은 줄임 표시 등 구분 가능하게(정확한 문구는 만드는 사람 재량, 번역표에 포함).
- 적용 중: 배경색 강조(기존 키들과 겹치지 않는 색, 예: 주황 계열). 대상이 0개면(모두 이미 음소거 등) 적용해도 표시는 켜되 아무것도 바꾸지 않음.
- OBS 연결 끊김: 기존 OFFLINE 표시.

## 설정 화면 (토크백 키)

1. Display name
2. 대상: "목록 제외 / 목록만" 선택
3. 소스 목록: 줄마다 소스 드롭다운(기존 소스 목록과 같은 데이터) + 삭제(×). 아래 **Add Source** 버튼.
4. 방식: 음소거 / 정한 볼륨 / 토크백. 정한 볼륨이면 "볼륨 (dB)" 칸, 토크백이면 "줄일 양 (dB)" 칸만 보임.
5. 동작: 누르는 동안 / 토글
6. (공통) OBS 연결 접힘 블록, 그 아래 **Language**.

## 언어

- 전역 설정 `language`: `ko` | `en` | `ja`, 기본 `en`.
- 설정 화면: 선택을 바꾸면 화면 문구가 바로 그 언어로 다시 그려짐.
- 키 글자: 플러그인이 전역 설정 변화를 받으면 모든 키를 다시 그림.
- OBS 연결 설정(host/port/password)과 언어는 분리: 언어만 바꿨을 때 OBS 재연결이 일어나면 안 됨.
- 번역 문구는 만드는 사람이 작성(일본어 포함). 키에 들어가는 짧은 글자는 기존 영어 글자와 비슷한 길이로, 키 밖으로 넘치지 않게.

## 토크백 키 여러 개가 같은 소스를 잡을 때 (사용자 요청)

- 소스마다 "맨 처음 줄이기 전 값" 하나만 기억한다. 두 번째 키가 이미 줄어든 소스를 잡아도 원래 값은 처음 값 그대로.
- 한 키가 꺼지면(떼거나 토글 끔) 그 키의 소스를 모두 원래 값으로 되돌린다. 그 소스를 같이 잡고 있던 다른 토크백 키도 **함께 꺼진다**: 남은 소스도 되돌리고, 토글 키는 꺼진 상태로 표시가 바뀐다. 그래서 "효과는 풀렸는데 키는 켜져 보이는" 헷갈리는 상태가 없다.
- 누르는 동안 방식 키가 이렇게 함께 꺼진 경우, 손을 떼도 더 할 일이 없다.

## 알려진 한계 (이번에 안 고침)

- PTT 키와 토크백이 같은 소스를 건드리면 마지막에 되돌린 쪽이 이긴다.

## 만드는 사람에게 맡기는 것

- 소스 목록을 설정에 저장하는 형식, Add Source/삭제 UI 구현 방법(sdpi-components 4.0.1 위에서).
- 강조 색, 키 글자 배치(기존 키 레이아웃과 어울리게), 번역 문구.
- 코드 구조(기존 `PttLatch` 확장 또는 새 클래스).
