# 프릭샷플러스용 별도 플러그인 설계

날짜: 2026-11-10 · 대상 저장소: `streamdeck-obs-audio` (Web-Socket Audio Controller 스트림덱 플러그인)

## 왜 만드나

프릭샷플러스(FreecShot Plus)는 SOOP이 OBS를 바탕으로 만든 방송 프로그램입니다. 사용자는 **OBS와 프릭샷플러스를 동시에** 씁니다.
그래서 지금 플러그인과 같은 기능(볼륨, 음소거, PTT/PTM, 토크백, 모니터링, 밸런스, 레벨 미터)을 프릭샷플러스에서도 키로 쓰고 싶습니다.

문제는 접속 설정입니다. 프릭샷플러스에는 obs-websocket이 들어 있지만 서버가 꺼져 있습니다. 또 켜는 메뉴가 화면에 없어서, 일반 사용자는 켤 수 없습니다.

## 시험으로 확인한 것 (2026-11-09)

- WebSocket 설정 파일 위치: `%APPDATA%\SOOPStudio\plugin_config\obs-websocket\config.json`
  - 처음 상태: `server_enabled: false`, `server_port: 4455`, `auth_required: true`, 비밀번호 16자가 이미 들어 있음.
- **방법:** 프릭샷이 꺼진 상태에서 위 파일의 `server_enabled`를 true로, `server_port`를 24455로 바꾸고 프릭샷을 켰습니다.
  - **결과:** 1.5초 만에 서버가 열렸습니다. 파일에 있던 비밀번호로 접속도 됐습니다.
- **버전:** OBS 31.0.4, obs-websocket 5.5.6입니다. 지금 플러그인이 쓰는 명령(GetInputList, Get/SetInputVolume, Mute, MonitorType, Balance)과 InputVolumeMeters 이벤트가 모두 그대로 동작했습니다.
- **SOOP 로그인 전에는** 접속은 되지만 명령마다 오류 코드 207("OBS is not ready")이 옵니다. 로그인하면 바로 정상으로 돌아옵니다.
- 프릭샷이 켜져 있는 동안 바꾼 설정은 그대로 남았습니다. **프릭샷을 껐다 켠 뒤에도 남는지는 아직 확인하지 않았습니다.**
- 이 PC의 Windows 동적 포트 범위는 1024–15000이라 24455는 다른 프로그램과 겹치지 않습니다.

## 목표

1. **별도 플러그인**: 스트림덱 목록에 OBS용과 따로 나타나는 플러그인입니다. 두 개를 함께 설치해도 서로 영향을 주지 않습니다.
   - 키 하나는 프로그램 하나만 조작합니다. OBS용 키는 OBS를, 프릭샷용 키는 프릭샷을 조작합니다.
   - 이름은 **Web-Socket Audio Controller for FreecShot Plus**입니다. 한국어 문서와 설명에서는 "프릭샷플러스용"이라고 씁니다.
   - 액션 종류, 설정 항목, 동작은 OBS용과 똑같습니다. 다른 점은 아래 2~5번뿐입니다.
2. **WebSocket 자동 설정 버튼**: 연결 설정 블록 안에 둡니다. 화면 순서는 다음과 같습니다.
   - 포트 칸: 비워 두면 **24455**를 씁니다.
   - 비밀번호 칸: 비워 두면 **프릭샷 설정 파일에 이미 있는 비밀번호**를 그대로 씁니다.
   - **[WebSocket 자동 설정]** 버튼과 결과 문구 한 줄.
   - 버튼을 누르면 플러그인이 다음 순서로 처리합니다.
     1. **SoopStudio.exe가 실행 중인지 확인합니다.** 실행 중이면 아무것도 바꾸지 않고 "프릭샷플러스를 완전히 끈 뒤 다시 눌러 주세요"라고 띄웁니다.
     2. **설정 파일을 찾습니다.** 없으면 "프릭샷플러스를 한 번 실행했다가 끈 뒤 다시 눌러 주세요"라고 띄웁니다. 파일 내용이 JSON이 아닐 때도 바꾸지 않고 알립니다.
     3. **바꾸기 전에 백업합니다.** 같은 폴더에 `config.json.bak-YYYYMMDD-HHMMSS`로 복사합니다. 백업이 실패하면 멈춥니다.
     4. **설정 파일을 바꿉니다.**
        - `server_enabled`를 true로, `server_port`를 입력한 값(또는 24455)으로 바꿉니다.
        - 비밀번호를 입력했다면 `auth_required`를 true로, `server_password`를 그 값으로 바꿉니다.
        - 비밀번호가 비어 있으면 인증 관련 값은 건드리지 않습니다.
        - 그 밖의 키는 그대로 둡니다.
     5. **플러그인 연결 설정을 맞춥니다.** host 127.0.0.1, 포트, 비밀번호를 프릭샷에 실제로 들어간 값으로 저장합니다. 그래서 프릭샷을 켜면 바로 연결됩니다.
     6. **결과를 알립니다.** "설정했습니다. 프릭샷플러스를 켜고 SOOP에 로그인하세요"라고 띄웁니다.
   - 비밀번호 값은 로그나 화면 문구에 절대 남기지 않습니다.
3. **로그인 대기 표시**
   - 접속은 됐는데 명령에 207이 오면, 키에 OFFLINE 대신 **로그인 대기**(영어 LOGIN, 일본어 ログイン待ち)를 띄웁니다.
   - 재시도는 지금처럼 3초마다 합니다.
4. **색: B안 "어두운 패널 + 하늘색 테두리"**
   - 키 바탕은 늘 `#171B1E`입니다.
   - 켜진 상태는 바탕을 칠하지 않고, **테두리와 글자 색**으로 보여줍니다.

     | 상태 | 테두리·글자 색 |
     | --- | --- |
     | PTT 말하는 중, 토크백 켜짐, 모니터링 켜짐 | 하늘색 `#0CC5FE` |
     | 음소거 | 빨강 `#FF4D5E` |
     | 꺼진 상태 | 테두리 없음, 흰 글자 |

   - 레벨 미터의 초록·노랑·빨강 구간은 OBS용과 똑같이 둡니다. 프로그램 화면의 믹서와 같은 방법으로 읽히게 하려는 것입니다.
   - 볼륨 위치 선만 하늘색 `#00D7FC`로 바꿉니다.
   - 색 값은 프릭샷플러스 화면에서 직접 뽑았습니다.

     | 요소 | 색 |
     | --- | --- |
     | 배경 | `#23262B` |
     | 패널 | `#171B1E` |
     | LIVE 버튼 | `#029CFE → #00D7FC` |
     | 상태 점 | `#45D865` |
5. **문구와 아이콘**
   - 연결 블록 제목은 "프릭샷플러스 연결 (WebSocket)"입니다. 안내 문구는 자동 설정 버튼을 안내합니다.
   - 아이콘은 지금 B 아이콘(레벨 미터 + 페이더)의 하늘색 버전입니다. **SOOP·프릭샷 로고는 쓰지 않습니다.**
   - README, 매니페스트 설명, 설명서에는 "SOOP과 관계없는 비공식 플러그인이며, FreecShot Plus·SOOP은 해당 회사의 상표"라는 문구를 넣습니다.
6. **배포**
   - 릴리즈 zip은 따로 만듭니다: `Web-Socket-Audio-Controller-for-FreecShot-Plus-StreamDeck-v<버전>.zip`. 버전은 사용자가 정합니다.
   - 설명서 PDF(ko/en/ja)와 README도 OBS용과 같은 형식으로 따로 만듭니다. 폰트는 Noto Sans KR이고, 일본어 한자는 Noto Sans JP로 대신합니다.

## 하지 않는 것

- 한 키로 OBS와 프릭샷을 같이 조작하는 기능.
- 프릭샷이 켜져 있는 동안 설정 파일을 바꾸는 것. 끌 때 프릭샷이 덮어쓸 수 있습니다.
- SOOP 로그인 자동화, 방송 시작·장면 전환 같은 오디오 밖의 기능.
- macOS 지원.
- OBS용 플러그인의 동작·색·문구 변경.

## 실패로 보는 것 (기술적으로 돌아가도)

- 자동 설정이 프릭샷 설정 파일을 망가뜨리거나, 백업 없이 바꾸는 경우.
- OBS용 플러그인이 조금이라도 다르게 동작하거나, 두 플러그인이 같은 설정·로그·상태 파일을 같이 쓰는 경우.
- 비밀번호가 로그, 화면, 저장소에 노출되는 경우.

## 방법 (검토한 것)

| 방법 | 내용 | 장단점 |
| --- | --- | --- |
| **A. 같은 저장소, 빌드할 때 두 가지로** (선택) | 코드 하나에 "OBS판/프릭샷판" 설정만 다르게 해서 플러그인 폴더 두 개를 만듭니다. | 고친 버그가 두 쪽에 같이 들어갑니다. 빌드 설정이 조금 복잡해집니다. |
| B. 저장소 복사(포크) | 프릭샷판을 새 저장소로 복사해 고칩니다. | 처음엔 쉽지만, 고칠 때마다 두 곳을 손봐야 하고 금방 어긋납니다. |
| C. 한 플러그인에서 프로그램 선택 | 키마다 OBS/프릭샷을 고릅니다. | 사용자가 "아예 별개의 플러그인"을 원해서 제외했습니다. |

사용자는 A를 골랐습니다. 이유는 같은 코드를 쓰면서 플러그인은 따로 보이게 하는 것입니다.

## 정해진 구조

- 프릭샷판 플러그인 폴더: `com.haeunga0822.freecshot-audio.sdPlugin`, UUID `com.haeunga0822.freecshot-audio`.
  - 액션 UUID는 `com.haeunga0822.freecshot-audio.<같은 이름>`입니다.
  - 지금은 `src/actions/common.ts`의 `ID`에 UUID가 고정돼 있습니다. 이것을 판(flavour)에 따라 정해지게 바꿉니다.
- 판마다 달라지는 값은 한곳(예: `src/flavour.ts`)에 모읍니다: UUID 앞부분, 기본 포트, 색 묶음, 연결 블록 문구 키, 자동 설정 버튼을 쓸지.
  - 빌드는 판마다 번들을 따로 만듭니다. 예를 들면 rollup 출력 두 개와 상수 치환입니다.
  - OBS판 번들은 지금과 똑같이 동작해야 합니다.
- 설정 화면(ui)의 공통 파일(`common.js`, `i18n.js`, `obs.html`, `sdpi-components.js`)은 같은 원본을 씁니다.
  - 판 정보는 각 플러그인 폴더의 작은 파일 하나로 알려줍니다.
  - 두 폴더에 복사하는 방법은 구현하는 사람이 정합니다.
- 자동 설정은 플러그인(node) 쪽에서 합니다. 설정 화면이 sendToPlugin으로 요청하고, 플러그인이 결과를 돌려줍니다.
  - 실행 확인은 Windows `tasklist` 결과에서 `SoopStudio.exe`를 찾는 방식입니다.
  - 설정 파일 경로는 `process.env.APPDATA` 기준입니다.
- 키 렌더링: 지금 `keys.ts`와 `meter.ts`의 색 상수(MUTED_BG, LIVE_BG, MONITOR_BG, TALKBACK_BG, 미터 선 색)를 색 묶음 객체로 바꿉니다.
  - B안은 "바탕 대신 테두리"라서, 켜짐 표시 방법(바탕 칠하기 / 테두리)도 색 묶음에 들어갑니다.

## 내가 정한 것 (확인 부탁)

- **백업 위치:** 설정 파일과 같은 폴더에, 시각을 붙인 이름으로 둡니다. 덮어쓰지 않으므로 여러 번 눌러도 백업이 쌓이기만 합니다.
- **포트 검사:** 입력할 수 있는 범위는 1024–65535입니다. 버튼을 누를 때 그 포트를 이미 다른 프로그램이 쓰고 있으면 바꾸지 않고 알립니다.
- **비밀번호를 비웠는데 프릭샷 파일에도 비밀번호가 없는 경우:** 인증 없이 둡니다. 플러그인 비밀번호도 빈 값으로 저장합니다.
- **로그인 대기 표시:** 프릭샷판만이 아니라 OBS판에도 그대로 들어갑니다. OBS는 207을 거의 보내지 않으니 OBS판 동작은 사실상 같습니다.
- **볼륨 위치 선 색:** B안 시안에 없던 부분이라, A안의 하늘색 `#00D7FC`를 가져왔습니다.

## 구현 전에 확인할 것

- **설정이 남는지:** 프릭샷을 껐다 켠 뒤에도 바꾼 설정이 남는지 확인합니다. 남지 않으면 자동 설정 방식을 다시 생각해야 하므로, 계획 첫 단계로 둡니다.

## 구현하는 사람에게 맡기는 것

- 빌드 스크립트 구성, ui 공통 파일 복사 방법.
- 하늘색 아이콘 파일(플러그인·카테고리·액션 아이콘)의 정확한 색 조정.
- 설명서 본문 구성. 형식은 OBS판 설명서를 따릅니다.
