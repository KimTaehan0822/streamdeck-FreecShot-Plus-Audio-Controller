Web-Socket Audio Controller for FreecShot Plus 스트림덱 플러그인 사용설명서

2026-11-10

스트림덱으로 프릭샷플러스(FreecShot Plus) 오디오 믹서의 볼륨, 뮤트, 모니터링, 밸런스를 바로 조절하고, 키와 다이얼 화면에서 레벨 미터를 보는 플러그인입니다. OBS용 Web-Socket Audio Controller와 따로 설치되므로, OBS와 프릭샷플러스를 함께 쓸 수 있습니다.

만든 사람: 닥터고블린 김탄2

준비물

아래 네 가지가 갖춰져 있어야 합니다.

항목필요한 것
컴퓨터Windows 10 이상
스트림덱 프로그램Stream Deck 소프트웨어 7.3 이상
프릭샷플러스FreecShot Plus (SOOP 방송 프로그램)
설치 파일.streamDeckPlugin 파일 (예: Web-Socket-Audio-Controller-for-FreecShot-Plus.streamDeckPlugin)

Stream Deck +가 있으면 다이얼 액션(VU Dial, Balance Dial)도 쓸 수 있습니다. 일반 스트림덱은 키 액션만 쓸 수 있습니다.

1단계: 플러그인 설치

  1. .streamDeckPlugin 파일을 더블클릭합니다.

  2. 스트림덱 프로그램이 열리면서 설치할지 물어봅니다. 설치를 누릅니다.

  3. 이미 설치되어 있다면 덮어쓸지 물어볼 수 있습니다. 이때도 설치를 고르면 됩니다.

  4. 스트림덱 프로그램 오른쪽 액션 목록에 Web-Socket Audio Controller for FreecShot Plus 카테고리가 생겼는지 확인합니다.

2단계: 프릭샷플러스 WebSocket 켜기 (자동 설정)

플러그인은 프릭샷플러스에 들어 있는 WebSocket이라는 기능으로 프릭샷플러스와 대화합니다. 이 기능은 처음에 꺼져 있고, 켜는 메뉴가 프릭샷플러스 화면에 없습니다. 그래서 플러그인의 WebSocket 자동 설정 버튼으로 한 번만 켭니다.

  1. 프릭샷플러스를 완전히 끕니다. 켜져 있으면 버튼이 아무것도 바꾸지 않고 알려 줍니다.

  2. 액션 목록의 Web-Socket Audio Controller for FreecShot Plus에서 아무 액션이나 하나 키에 끌어다 놓고 클릭합니다.

  3. 아래 설정 화면 맨 밑의 ▶ FreecShot Plus connection (WebSocket)을 눌러 펼칩니다.

  4. Port와 Password는 보통 비워 둡니다. 비워 두면 포트는 24455, 비밀번호는 프릭샷플러스에 이미 들어 있는 것을 씁니다. 원하는 값이 있으면 넣습니다(포트는 1024–65535).

  5. WebSocket auto setup(한국어 설정이면 WebSocket 자동 설정) 버튼을 누릅니다. "설정했습니다"가 뜨면 끝입니다. Port와 Password 칸에도 실제로 들어간 값이 채워집니다.

  6. 프릭샷플러스를 켜고 SOOP에 로그인합니다. 로그인하기 전에는 키에 LOGIN(한국어 설정이면 로그인 대기)이 뜹니다.

버튼은 바꾸기 전에 원래 설정 파일을 같은 폴더에 config.json.bak-날짜-시각으로 백업합니다. 설정 파일 위치: %APPDATA%\SOOPStudio\plugin_config\obs-websocket\config.json

3단계: 플러그인 연결

2단계의 자동 설정 버튼이 연결 설정까지 채워 주므로, 보통은 여기서 바꿀 것이 없습니다. 값을 확인하거나 직접 고칠 때 아래를 보세요.

  1. 액션 목록의 Web-Socket Audio Controller for FreecShot Plus에서 아무 액션이나 하나 키에 끌어다 놓고 클릭합니다.

  2. 아래 설정 화면 맨 밑의 ▶ FreecShot Plus connection (WebSocket)을 눌러 펼칩니다. (평소에는 접혀 있습니다)

  3. 값을 확인하거나 고칩니다. 여기서 바꾼 값은 모든 액션에 같이 적용됩니다.

항목기본값뜻
Host127.0.0.1프릭샷플러스가 돌아가는 컴퓨터 주소 (같은 PC면 그대로)
Port24455프릭샷플러스의 서버 포트와 같아야 함 (자동 설정이 맞춰 줌)
Password비어 있음프릭샷플러스의 WebSocket 비밀번호 (자동 설정이 채워 줌)

값을 바꾸면 스트림덱을 다시 켜지 않아도 바로 다시 연결합니다. 프릭샷플러스가 꺼져 있으면 키에 OFFLINE이 뜨고, 3초마다 다시 연결을 시도합니다.

언어 바꾸기: 같은 설정 화면 맨 아래의 ▶ Language를 펼쳐 English / 한국어 / 日本語 중에서 고릅니다. 고르는 즉시 설정 화면의 글자와 키에 뜨는 글자(MUTED, OFFLINE 등)가 함께 바뀌고, 모든 액션에 같이 적용됩니다. 처음 값은 English이고, 액션 목록의 액션 이름은 바뀌지 않습니다.

연결됐는지 확인하는 법: 키에 OFFLINE이 안 뜨고, 설정 화면의 Source 목록에 프릭샷플러스의 오디오 소스 이름(예: 마이크, 데스크톱 오디오)이 보이면 연결된 것입니다.

4단계: 첫 키 만들어 보기

마이크를 키 하나로 뮤트하는 예시입니다. 모든 스트림덱에서 쓸 수 있습니다.

  1. 액션 목록의 Web-Socket Audio Controller → Mute를 빈 키에 끌어다 놓습니다.

  2. 키를 클릭하고 아래 설정 화면의 Source에서 마이크 소스를 고릅니다. 소리가 없는 소스(이미지, 브라우저 등)는 목록에 나오지 않습니다.

  3. 키를 누를 때마다 뮤트가 켜지고 꺼집니다. 뮤트 중에는 빨간 테두리와 옅은 빨간 바탕에 소스 이름과 MUTED(한국어 설정이면 음소거)가 가운데에 뜹니다.

프릭샷플러스에서 소스 이름을 바꿔도 키 설정은 그대로 유지됩니다.

키 두 개로 볼륨 페이더 만들기

마이크 볼륨을 키 두 개로 올리고 내리는 예시입니다. 모든 스트림덱에서 쓸 수 있습니다.

  1. Fader(2-Button)를 위아래로 붙어 있는 두 칸에 하나씩 끌어다 놓습니다.

  2. 위쪽 키를 클릭하고 Source에서 마이크를, Role에서 Top (up)을 고릅니다.

  3. 아래쪽 키도 같은 소스를 고르고, Role만 Bottom (down)으로 고릅니다.

  4. 위쪽 키를 누르면 볼륨이 1 dB 올라가고, 아래쪽 키를 누르면 1 dB 내려갑니다. 누르고 있으면 계속 움직입니다. 한 번에 움직이는 양은 Step (dB) 칸에서 바꿀 수 있습니다(예: 0.5, 2).

좌우로 나란히 놓고 싶다면 Role을 Left (down)와 Right (up)로 고르세요.

화면 보는 법 (위아래로 놓았을 때):

  • 위쪽 키의 윗부분: 소스 이름과 현재 볼륨

  • 아래쪽 키의 아랫부분: 지금 소리 레벨

  • 막대 2줄(L/R): 지금 들어오는 소리 크기. 두 키에 걸쳐 하나로 이어지고, 눈금은 프릭샷플러스처럼 −60 ~ 0 dB

  • 막대 안의 하늘색 선: 볼륨(페이더) 위치

  • MUTED: 뮤트 상태 (막대는 회색으로 계속 움직임)

소스 이름은 페이더 크기를 맞추려고 항상 한 줄로 나옵니다. 너무 길면 끝이 …로 줄어드니, Display name에 짧은 이름을 넣으세요. 이 키로는 뮤트를 켜고 끌 수 없습니다. 뮤트도 키로 하려면 Mute 액션을 하나 더 놓으세요.

Stream Deck +라면: VU Dial로 만들어 보기

마이크 볼륨을 Stream Deck + 다이얼로 조절하는 예시입니다.

  1. VU Dial을 다이얼 칸에 끌어다 놓습니다.

  2. 설정 화면의 Source에서 마이크를 고릅니다.

  3. 다이얼을 한 칸 돌릴 때마다 1 dB씩 볼륨이 바뀝니다. 한 칸에 움직이는 양은 Step per tick (dB) 칸에서 바꿀 수 있습니다(예: 0.5, 2). 누르고 떼면 뮤트가 켜지고 꺼집니다.

화면 보는 법:

  • 맨 위: 소스 이름

  • 막대 2줄(L/R): 지금 들어오는 소리 크기 (초록 → 노랑 → 빨강)

  • 막대 안의 하늘색 선: 볼륨 위치

  • 아래 왼쪽 / 오른쪽: 소리 레벨 / 볼륨 값

  • MUTED: 뮤트 상태

화면을 손가락으로 터치해도 뮤트됩니다. 실수로 자꾸 눌린다면 Touch tap mutes를 끄세요. 아래 왼쪽 레벨 숫자는 Level text에서 L/R 따로(L -14.0 R -18.0) 또는 큰 값 하나(Combined, -14.0 dB)로 고를 수 있습니다.

누르기 동작 바꾸기: 설정 화면의 ▶ Press actions를 눌러 펼칩니다. (평소에는 접혀 있습니다)

  • Press: 누르고 뗐을 때. Mute toggle(기본) 또는 Recall volume

  • Press + turn left / right: 누른 채 왼쪽 / 오른쪽으로 돌릴 때. Step volume(기본), Mute toggle, Mute on, Mute off, Recall volume

  • Recall volume을 고르면 그 아래에 Recall volume (dB) 칸이 나옵니다. 돌아갈 볼륨을 적으세요(예: −20).

누른 채 돌렸다면 손을 뗄 때 누르기 동작은 실행되지 않습니다.

액션 목록

키는 모든 스트림덱에서, 다이얼은 Stream Deck +에서만 쓸 수 있습니다.

누르고 있으면 반복되는 키(Fader(2-Button), Volume의 Step by, Balance의 Step by)는 반복이 멈추지 않으면 그 키를 한 번 더 눌러 멈출 수 있습니다.

Volume과 Balance 키

Volume: Mode에서 고릅니다.

  • Set to: Volume (dB)에 적은 값으로 맞춥니다(예: −20).

  • Step by: 적은 만큼 올리거나 내립니다(예: 1 또는 −1). 누르고 있으면 계속 움직입니다.

볼륨 범위는 프릭샷플러스 슬라이더처럼 −∞ ~ 0 dB입니다. 내리다가 −60 dB 아래로 가면 −∞(무음)가 되고, −∞에서 올리면 −60 dB가 됩니다.

Balance: Mode에서 고르고 Balance 칸에 값을 적습니다.

  • Set to: −100 = L 100, 0 = 가운데, 100 = R 100 (예: −40 → L 40)

  • Step by: 5 = 오른쪽으로 5, −5 = 왼쪽으로 5

Push to talk / Push to mute

  1. Push to talk / Push to mute를 키에 놓고 Source에서 마이크를 고릅니다.

  2. Mode에서 고릅니다. Push to talk는 누르는 동안만 소리가 나가고, Push to mute는 누르는 동안만 소리가 막힙니다.

  3. Release delay (ms): 손을 뗀 뒤 이만큼 기다렸다가 되돌립니다(기본 200 ms, 프릭샷플러스의 PTT와 같음). 말끝이 잘리지 않게 해 줍니다.

키에는 소스 이름과 동작 방식(Push to talk 또는 Push to mute, 한국어 설정이면 누르면 말하기 / 누르면 음소거)이 뜹니다. 소리가 나가는 중에는 하늘색 테두리와 옅은 하늘색 바탕, 막혀 있으면 글자가 빨간색입니다.

  • 누르는 순간의 뮤트 상태를 기억하고, 손을 떼면 누르기 전 상태로 되돌립니다. 이미 뮤트된 마이크에 Push to mute를 눌렀다 떼도 마이크가 켜지지 않습니다.

  • 누르고 있는 중에 페이지를 바꾸면 바로 되돌립니다. 프릭샷플러스 연결이 끊긴 사이에 손을 떼면 다시 연결되는 순간 되돌립니다.

  • Multi Action 안에서는 동작하지 않습니다. 키를 뗀 신호가 확실하지 않아 마이크가 켜진 채 남을 수 있기 때문입니다.

Talkback (토크백)

말할 때 배경음악이나 게임 소리를 한꺼번에 줄이는 키입니다.

  1. Talkback을 키에 놓습니다.

  2. Target에서 고릅니다. All except the list는 목록의 소스(보통 내 마이크)를 뺀 전부, Only the list는 목록의 소스만 줄입니다.

  3. + Add Source를 눌러 목록에 소스를 한 줄씩 추가합니다. 줄 오른쪽의 ×로 지웁니다.

  4. Style에서 줄이는 방식을 고릅니다.

  5. Behavior에서 While held(누르는 동안만) 또는 Toggle(한 번 누르면 켜지고, 다시 누르면 꺼짐)을 고릅니다.

Style하는 일
Mute대상 소스를 음소거
Set volumeVolume (dB)에 적은 볼륨으로 내림(기본 −30). 이미 더 작은 소스는 그대로
Talkback지금 볼륨에서 Lower by (dB)만큼 내림(기본 15)

  • 켜진 동안 키에 하늘색 테두리와 옅은 하늘색 바탕이 생깁니다. 이미 음소거된 소스는 건드리지 않습니다.

  • 끄면 누르기 전 값으로 돌립니다.

  • 토크백 키 여러 개가 같은 소스를 잡고 있으면, 하나를 끌 때 그 소스를 같이 잡은 키도 함께 꺼지고 표시도 꺼짐으로 바뀝니다.

  • 스트림덱 앱이나 PC를 다시 켜도 원래 값을 기억합니다. While held는 프릭샷플러스에 연결되는 즉시 되돌리고, Toggle은 켜진 채로 이어집니다.

  • Toggle이 켜진 상태로 키를 지우면 소스가 줄어든 채 남으니, 끄고 나서 지우세요.

  • Multi Action 안에서는 Toggle만 동작합니다.

Audio monitoring

프릭샷플러스의 오디오 고급 속성에 있는 오디오 모니터링을 키로 바꿉니다. Mode에서 고릅니다.

Mode하는 일
Set toMonitoring에서 고른 값(Monitor off / Monitor only / Monitor and output)으로 맞춤
Toggle with off누를 때마다 끔과 고른 값을 번갈아 바꿈
Cycle누를 때마다 끔 → 모니터만 → 모니터와 출력 순서로 바꿈

키에는 소스 이름과 지금 모니터링 상태가 뜨고, 모니터링이 켜져 있으면 하늘색 테두리와 옅은 하늘색 바탕이 됩니다.

미터 설정

미터가 있는 액션(VU Dial, Fader(2-Button), Volume)에는 Meter style이 있습니다. 프릭샷플러스 설정 → 오디오 → 피크 미터 유형과 같은 쪽을 고르세요.

Meter style프릭샷플러스 설정색 구간
Standard샘플 피크노랑 −20 dB, 빨강 −9 dB부터
Wide green트루 피크노랑 −13 dB, 빨강 −2 dB부터

프릭샷플러스는 플러그인에 샘플 피크 값만 보내 줍니다. 그래서 Wide green은 색 구간만 프릭샷플러스와 같고, 큰 소리가 튈 때 프릭샷플러스 화면보다 아주 조금 낮게 보일 수 있습니다. 미터는 프릭샷플러스처럼 피크가 천천히 내려가고, 피크 홀드 표시가 20초 동안 남습니다.

키 표시 바꾸기

소스 이름 바꾸기: 설정 화면의 Display name 칸에 원하는 이름을 넣습니다. 비워 두면 프릭샷플러스의 소스 이름이 나옵니다. 스트림덱 자체의 제목 칸을 쓰면 플러그인 글자와 겹치므로, 이름은 Display name으로 바꾸세요.

상태별로 다르게 보이기: Mute, Push to talk / Push to mute, Talkback, Audio monitoring 키는 상태가 두 개입니다.

  1. 스트림덱 프로그램에서 그 키를 클릭합니다.

  2. 아이콘 아래에 보이는 점 두 개를 확인합니다. 점마다 어떤 상태인지는 아래 표를 보세요.

  3. 점을 누른 뒤 그 상태에서 보일 아이콘과 제목을 정합니다.

키왼쪽 점오른쪽 점
Mute소스의 소리가 나갈 때소스의 소리가 꺼졌을 때(음소거)
Talkback다른 소스들의 소리가 그대로 나갈 때다른 소스들의 소리가 꺼졌거나 줄어들었을 때(토크백 켜짐)
Push to talk소스의 소리가 나갈 때(누르고 있을 때)소스의 소리가 꺼졌을 때(보통 누르지 않을 때)
Push to mute소스의 소리가 나갈 때(보통 누르지 않을 때)소스의 소리가 꺼졌을 때(누르고 있을 때)
Audio monitoring모니터링이 꺼졌을 때모니터링이 켜졌을 때(모니터만 또는 모니터와 출력)

제목을 넣으면 플러그인이 그리는 이름과 상태 글자는 사라집니다(테두리와 바탕색은 그대로). 직접 넣은 아이콘이 보이는 동안에는 OFFLINE 같은 표시가 안 보일 수 있습니다. 점이 하나만 보이면 예전 버전에서 놓은 키입니다. 그 키를 지우고 액션 목록에서 다시 끌어다 놓으세요.

키에 뜨는 표시와 문제 해결

키나 다이얼에 아래 글자가 뜨면 오른쪽 열의 순서대로 확인하세요. 언어를 한국어로 골랐다면 괄호 안의 글자로 뜹니다.

표시 / 증상뜻할 일
OFFLINE (오프라인)프릭샷플러스에 연결되지 않음프릭샷플러스가 켜져 있는지 → 2단계 자동 설정을 했는지 → 포트 24455 → 비밀번호 순서로 확인
LOGIN (로그인 대기)연결은 됐지만 SOOP 로그인 전이라 프릭샷플러스가 명령을 받지 않음프릭샷플러스에서 SOOP에 로그인. 로그인하면 바로 사라짐
SET SOURCE (소스 선택)소스를 아직 안 고름액션을 클릭하고 설정 화면에서 Source 선택
SETUP (설정)다른 필수 설정이 비어 있음설정 화면의 빈 칸(Mode, 값 등) 채우기
N/A고른 소스가 프릭샷플러스에 없음(삭제됨)다른 소스 고르기
레벨 막대가 안 움직임그 소스에 소리가 안 들어옴프릭샷플러스 오디오 믹서에서 그 소스의 미터가 움직이는지 확인
Source 목록이 비어 있음아직 연결 전연결되면 목록이 채워짐. 안 되면 OFFLINE 항목 확인
반복이 안 멈춤키를 놓은 신호를 못 받음그 키를 한 번 더 누르기
토크백을 껐는데 소리가 작음켜진 채 키를 지웠거나 프릭샷플러스 연결이 끊김프릭샷플러스 연결을 확인. 키를 지웠다면 프릭샷플러스에서 볼륨을 직접 되돌리기
